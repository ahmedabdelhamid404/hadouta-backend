# Theme: First Day of School (المدرسة الأولى)

The MVP theme for Hadouta v1. Lives here as data/content, NOT in code — so adding new themes later requires no code changes.

## Files (to be filled in Sprint 2-3)

- `system-prompt.md` — Claude Sonnet 4.6 system prompt for generating FDS stories
- `few-shot-examples.json` — 3-5 reference stories (commissioned from Egyptian children's writer)
- `validator-rules.json` — theme-specific validator rules (must mention school + teacher + appropriate moral arc)
- `reference-stories/` — full text + JSON of gold-standard FDS stories
- `setting-prompts.md` — image prompt fragments for FDS-specific scenes (Cairo balcony morning, school gate, classroom, recess, etc.)

## Cultural framing

- Egyptian school year starts ~early September
- Audience: parents of 3-5yr olds
- Story arc: anxiety → reassurance → arrival → meeting friends → pride
- Family characters: mom often present at drop-off; dad or grandparent optional
- Settings: Cairo balcony morning routine, school gate goodbye, classroom intro, recess play, return home
